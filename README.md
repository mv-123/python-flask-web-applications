There are 5 Flask projects in this repository. Each folder contains an image of what the project looks like.

1. Image Gallery: Allows the user to upload images onto the website. The user can see the uploaded images on the website.
2. News: Searches the news based on the topic. Displays a picture of the article along with the title and a brief description.
3. REST Countries: Shows the basic information of the searched country.
4. User Authentication: A login and registration page. Also includes a data page that displays all of the login information.
5. Weather: Shows the basic weather information of the searched area.
